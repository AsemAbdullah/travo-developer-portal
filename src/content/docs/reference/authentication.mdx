## Overview

The Travo ERP API uses **API key authentication**. Every request must include this header:

```
X-API-Key: your-api-key-here
```

## How Keys Work

| Property | Detail |
|---|---|
| **Issued by** | Travo, per company, per program |
| **Scope** | One key = one company + one program |
| **Expiration** | Keys have an `ExpireDate`. An expired key returns `401`. |
| **Rate limiting** | Requests are rate-limited per key. Exceeding the limit returns `429`. |

## Key Properties

Your API key is bound to:

- **A company** — every invoice you push belongs to this company.
- **A program** — determines whether you're on SCF (financing) or Collection.
- **An integration name** — a human-readable label for your integration (e.g., "Odoo Production").

If your company operates both program types, you receive **two separate keys**.

## Error Responses

| Status | Cause | Action |
|---|---|---|
| `401` | Missing header | Add `X-API-Key` to every request |
| `401` | Unknown key | Verify you're using the correct key for the environment |
| `401` | Expired key | Contact Travo to renew your key |
| `401` | Inactive key | Your key was deactivated — contact Travo |
| `429` | Rate limit hit | Back off (exponential backoff recommended) |

<Aside type="tip">
Call `GET /api/erp/me` once at startup and log the result. If it returns `401`, you know immediately — before your first business call fails.
</Aside>

## Security Best Practices

1. **Never commit your API key** to version control. Use environment variables or a secret manager.
2. **Use separate keys** for sandbox and production.
3. **Rotate keys** periodically — coordinate with Travo to issue a new key and deprecate the old one.
4. **Always use HTTPS** — never send your key over unencrypted HTTP.

## Inbound Key Exchange

If you host your own ERP endpoint (e.g., Odoo) and Travo needs to call back into it, the [inbound key handshake](/reference/me/) lets the two systems exchange credentials directly:

```
POST /api/erp/inbound-key
{
  "erpApiKey": "<key-for-travo-to-call-you>",
  "erpEndpointUrl": "https://your-erp.example.com/api/erp/odoo/invoices"
}
```

This stores the key Travo will present when pulling invoices from your system.
