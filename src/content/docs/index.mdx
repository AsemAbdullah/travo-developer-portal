## Two program types, one API

Your API key determines which flow applies. You never choose per request.

| | **SCF (Financing)** | **Collection** |
|---|---|---|
| Program owner | Buyer | Supplier |
| API key holder | Buyer | Supplier |
| `nationalId` on each invoice | Supplier | Buyer |
| Fee quote step? | Yes | No |
| Final endpoint | `/invoices/early-payment` | `/invoices/request-to-pay` |
| Bank approval workflow? | Yes | No |

Not sure which one you have? Call [`GET /api/erp/me`](/reference/me/) — it tells you.

## How it works

```
GET  /api/erp/me                              → discover your program type
POST /api/erp/invoices/bulk                   → push invoices
POST /api/erp/invoices/early-payment/details  → get fee quote (SCF only)
POST /api/erp/invoices/early-payment          → submit financing (SCF)
POST /api/erp/invoices/request-to-pay         → bill the buyer (Collection)
POST /api/erp/invoices/status                 → track the invoice
POST /api/erp/invoices/update                 → patch an invoice
POST /api/erp/invoices/delete                 → soft-delete an invoice
GET  /api/erp/bank-accounts                   → list bank accounts
POST /api/erp/Create/bank-account             → add a bank account
GET  /Lookups/Banks                           → list available banks
GET  /Lookups/Programs                        → list joined programs
```

## Security

Every request requires an `X-API-Key` header. Keys are issued per company, per program. A missing, unknown, inactive, or expired key returns `401`.

Everything in this portal runs locally in your browser — API keys and responses are never sent to CreditPlus's documentation servers.
